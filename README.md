# Tareas App — PHP MVC

Proyecto personal para practicar los fundamentos de una aplicación web 
con arquitectura MVC en PHP vanilla.

## Características
- Arquitectura MVC en PHP puro sin frameworks
- API REST con autenticación JWT
- Subida y gestión de imágenes
- Envío de correos con PHPMailer

## Tecnologías
- PHP 8
- MySQL / MariaDB
- JWT para autenticación
- PHPMailer para emails
